Todo List — приложение «Список дел»

Учебный проект по JavaScript. Реализован на чистом JS (ES6/ES7), без фреймворков и библиотек.  
Вёрстка адаптивная, без багов на всех вьюпортах.

## Демо
http://dardurranisc.github.io/todolist/

## Стек
- HTML5
- CSS3
- JavaScript (ES6/ES7) — без фреймворков и библиотек
- LocalStorage — для сохранения данных

## Функционал
- Добавление новой задачи
- Редактирование задачи
- Удаление задачи
- Отметка задачи как выполненной
- Фильтрация: все / активные / выполненные
- Сохранение задач в LocalStorage
- Сохранение состояния фильтра
- Валидация ввода (пустая задача не добавляется)
